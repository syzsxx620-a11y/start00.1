# ✍️ 学术工具箱 — 论文写作工具导航

一个纯静态的单页网站，汇集学术论文写作全流程的实用工具，帮助你从选题到投稿的每一步都找到趁手的工具。

## ✨ 功能特性

- **30+ 精选工具**，按 7 大场景分类（文献管理、写作润色、AI 辅助、查重降重、排版绘图、数据分析、协作笔记）
- **关键词搜索 + 分类筛选**，实时过滤工具
- **热门工具横向对比表**，快速做出选择
- **写作流程推荐**，按阶段推荐工具
- **FAQ 折叠问答**，解答新手常见问题
- **响应式设计**，桌面 / 平板 / 手机自适应
- **零依赖**，单个 HTML 文件即可离线运行

## 🚀 使用方法

直接双击 `index.html` 用浏览器打开即可，无需安装任何依赖或运行服务器。

也可以本地起一个静态服务：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
